OOP Study Guide
Object: an instance of a class that holds its own data and behavior.
Methods: functions defined inside a class that describe what its objects can do.
Classes: blueprints that define the fields and methods an object will have.
Every object is created from a class, and each object keeps its own state.
Objects interact by calling each other's methods.

Encapsulation: bundling data and the methods that operate on it inside one class.
Encapsulation protects an object's internal state from outside interference.
Good encapsulation means other classes use public methods instead of touching fields directly.

Inheritance: a mechanism where a subclass acquires the fields and methods of a superclass.
Inheritance promotes code reuse across related classes.
A subclass can override methods it gets through inheritance.

Polymorphism: the ability of one interface to be used with many different underlying types.
Polymorphism lets a single method call behave differently depending on the object.
Overriding is a common way to achieve polymorphism in Java.

Abstraction: hiding complex implementation details and exposing only what is necessary.
Abstraction is often achieved with abstract classes and interfaces.
Abstraction keeps programmers focused on what an object does, not how it does it.
